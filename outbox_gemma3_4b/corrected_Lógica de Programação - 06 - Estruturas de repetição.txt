Estruturas de repetição são recursos que permitem repetir a execução de porções de código enquanto uma condição for avaliada como verdadeira ou até que uma condição seja avaliada como verdadeira. Para tanto, utilizaremos os blocos “repita enquanto”. Vejamos o bloco “repita enquanto”.

Utilização do bloco “repita enquanto” requeremos uma variável. Vamos criar a variável “n” esta variável “n” será utilizada para passar um valor inicial para ela, este caso, zero. E vamos colocar uma condição: “se n é menor ou igual a cinco”. Compararemos “n” com o valor cinco.  A declaração ficará da seguinte forma: "repita enquanto n é menor ou igual a cinco".  No caso, repita enquanto n < 5.

Repita enquanto a variável “n” contiver um valor. Para que isso aconteça, é necessário que o valor de “n” se modifique durante a execução, porque o laço iterações a cada vez que o valor de “n” altera.  Vamos colocar um bloco “define n” para o valor matemático 1.  Nesse caso, o valor de “n” aumenta de uma unidade a cada vez que o bloco é executado.  E vamos exibir o valor determinado.  Como fazemos isso? Vamos do blog na seção texto pegar o bloco “imprimir” e colocar aqui para que ele exiba o valor da variável “n”. Vejamos a execução: a primeira vez que o bloco é executado, o valor de “n” é zero. Então incrementa (aumenta em 1) o valor de “n” que se torna um.  Chama “imprimir” e exibe na tela o primeiro valor de “n” (1).  A variável “n” passa a valer um.  Ele volta para o início do uso do laço.
