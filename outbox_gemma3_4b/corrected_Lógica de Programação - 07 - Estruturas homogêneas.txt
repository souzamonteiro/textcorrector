olá nesta aula aprenderemos sobre estruturas homogêneas. Estruturas homogêneas são vetores, no qual podemos armazenar valores de diversos tipos. A maioria das linguagens de programação permite que se armazene números, strings e até objetos complexos. Neste curso, nós iremos armazenar um número especificamente, nesta aula números. Para trabalhar com listas ou vetores, utilizamos a seção lista, a paleta de listas e os blocos "criar lista", "definir" e "obter um elemento de vista". Vamos criar uma variável chamada "nota" e vamos utilizar essa variável para solicitar a digitação de notas pelo usuário. "Nota definir nota". Para criar uma lista para transformar a variável "nota" em uma lista, utilizaremos o bloco "criar lista". Com o bloco, possui três posições por padrão, mas podemos acrescentar qualquer quantidade de posições que desejarmos. Se simplesmente arrastamos o item da aba "baixo" para a quarta posição da lista, caso deixemos somente três posições. Para inicializar os elementos da lista, neste caso, já que uma lista de números, utilizamos o bloco numérico. Vou colocar os valores 1, 2, 3.  Já que criamos uma lista para percorrer os elementos desta lista, já que a lista estrela possui três posições, nós vamos utilizar um laço de repetição "comprar". Com este laço, contar quantos elementos existem. Vamos criar uma variável "contador" com um valor padrão de 0. Podemos criar outras variáveis se desejarmos. Quando utilizava grave, gravemente os ornamentos de lista no ambiente de blocos são numerados a partir da primeira posição, como casamento, um, dois, três e assim por diante. Assim, o "contador" começa no número um indo até o número dez por padrão, mas nossa lista só tem três posições. Vamos alterar a posição para três, para que nós possamos preencher cada um dos elementos da lista. Mas vamos utilizar o bloco "definir lista" e vamos colocar na posição logo após a palavra "número", a variável "i". Use os valores 1, 2, 3.  Agora, vamos pegar o bloco "se", para que, quando utilizimos a estrutura de dados, não precisamos fazer nenhuma operação de vetor. O "se" nos permite solicitar a digitação dos dados. Vamos criar uma variável "contador" com um valor padrão de 0. Podemos criar outras variáveis se desejarmos. Assim, o "contador" começa no número um indo até o número dez por padrão, mas nossa lista só tem três posições.
