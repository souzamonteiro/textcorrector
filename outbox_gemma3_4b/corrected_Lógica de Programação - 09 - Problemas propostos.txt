O segundo problema consiste em criar uma função que receba um número inteiro em seguida calcule seu fatorial. O valor do fatorial deve ser exibido na tela. É importante lembrar que o fatorial de n é calculado da seguinte forma: n! = n * (n-1) * (n-2) * ... * 1.

Como exemplo, temos o fatorial de 5: 5! = 5 * 4 * 3 * 2 * 1 = 120.

Para exibir os resultados, utilizamos o bloco "função" na aba "Obtenção". Obtemos o bloco "função fatorial" e renomeamos para "fatorial". Dentro do bloco "função", adicionamos um bloco cinza para fazer a comparação "se". Se o valor de n for maior que 0, então o resultado é definido como n * fatorial(n-1). Caso contrário, o resultado é definido para 1.

Utilizamos recursão para calcular o fatorial.  A função fatorial é chamada a si mesma para calcular o fatorial de números menores até 1.
