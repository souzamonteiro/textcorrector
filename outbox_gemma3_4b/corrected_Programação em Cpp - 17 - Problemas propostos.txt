Olá, nesta aula resolveremos alguns problemas propostos. Nosso primeiro problema consiste em construir um programa que verifique se uma palavra dada é um palíndromo. Um palíndromo é uma palavra que, da mesma forma, de frente para trás e de trás para frente. Por exemplo, “arara”. Tente resolver o problema e depois retorne vídeos para ver a minha solução. Vamos resolver o problema ou criar um novo documento.

Vamos criar um programa que agora não esteja preparado para resolver esse problema. Vou criar algumas variantes. A primeira palavra será "série". A primeira variável será uma variável de controle que vai percorrer a expressão da esquerda para a direita. Essa variável se chamará "i". A segunda variável será uma outra variável de controle que vai percorrer a expressão da direita para a esquerda. Essa variável também será uma variável inteira e se chamará "j". Vamos criar um vetor de caracteres. Uma variável do tipo caracter, que vai conter até duzentas e quarenta e cinco caracteres. Vou pedir para que o usuário entre uma palavra. Por exemplo, "palavra". Em seguida, vou ler a palavra digitada pelo usuário. O programa para que os próximos textos apareçam todos abertos.

Vamos criar um novo arquivo para facilitar sua noite. A propaganda dos outros estima-se que de momento sim, o piquenique porto no fundo feito. Nossa parte bem podia dizer apenas o esqueleto do texto. O programa do palíndromo para facilitar isso vai digitar o nome. Vamos criar uma variável chamada "tamanho" (20). No entanto, pode usar um contador para contar o número de vogais. Contar a começar do zero. O valor é zero. E muito menos é certo do nome da pessoa. Não importa para cada letra do nome, incrementar o valor descontado, caso seja uma das vogais.  Por exemplo, se a letra é 'a', 'e', 'i', 'o' ou 'u', incrementar o valor descontado. O programa vai verificar a posição "n". Tudo igual.

Vamos testar se a palavra é "arara".  Vamos verificar se qualquer uma das suas letras é uma vogal. Se sim, incremento o valor descontado.  A palavra "arara" tem três vogais.
