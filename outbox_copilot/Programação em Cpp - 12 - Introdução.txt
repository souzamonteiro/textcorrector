A linguagem de programação que usaremos tem uma peculiaridade: ela é derivada da linguagem de sinais. Em 1972, o professor Dennis Ritchie lançou a linguagem C como uma linguagem não padrão para o projeto Unix. A ideia era criar uma nova linguagem de programação que permitisse o desenvolvimento de sistemas operacionais. A linguagem C foi criada nos anos 60 pela Bell Labs, uma subsidiária da AT&T, para aproveitar ao máximo a capacidade dos computadores da época. Esses computadores eram muito poderosos para sua época, mas muitos de seus recursos eram subutilizados porque os programas eram carregados no contador de programa e tinham que realizar uma série de processos, incluindo a leitura de fitas magnéticas ou cartões perfurados. Durante esses acessos de leitura, o processador ficava ocioso, aguardando os dados. Como apenas uma pessoa usava o computador por vez, o processador tinha muito mais capacidade do que o necessário.

O sistema operacional Unix, desenvolvido por Ritchie e sua equipe, foi um avanço significativo porque permitiu o compartilhamento de recursos entre usuários e programas. Isso significava que os recursos mais poderosos do computador poderiam ser utilizados de forma mais eficiente.
