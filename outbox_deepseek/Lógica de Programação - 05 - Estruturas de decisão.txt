Nesta aula, falaremos sobre estruturas de decisão. Estruturas de decisão são recursos que permitem ao programador criar porções de código que serão executadas somente se uma determinada condição for avaliada como verdadeira.

Para criarmos estruturas de decisão, utilizamos o bloco "se". Mas antes, vamos criar algumas variáveis. Vou criar uma variável chamada "nota". Vamos utilizá-la para armazenar o valor que o usuário digitar. Para isso, vamos utilizar um novo bloco, que ainda não utilizamos: o bloco "perguntar". Ele permite que uma caixa de diálogo seja exibida e o usuário digite uma resposta. Uma mensagem será apresentada. Neste caso, a mensagem será "Informe a nota". Este bloco permite que se configure a resposta como texto ou número. Neste momento, vamos utilizar como número.

Se executarmos o programa somente com este bloco, será exibida a caixa de texto onde podemos digitar. Se digitarmos 10 e clicarmos em OK, o valor será armazenado na variável "nota". Se pedirmos que seja fornecido um texto, quando o usuário digitar a nota, mesmo que seja digitado um número, internamente a linguagem de programação vai interpretar aquilo como texto, não como um valor numérico que possa ser trabalhado. Se queremos fazer algum tipo de processamento com este valor, precisamos então pedir um número ou forçar a conversão. Veremos como utilizar isso daqui a pouco.

Vou agora criar um bloco "se". Colocando o bloco "se", nós queremos agora exibir duas mensagens na tela, mas cada uma dessas mensagens será exibida somente se uma determinada condição for avaliada como verdadeira. A condição padrão que nós vamos colocar é: com o bloco de lógica, vamos pegar um bloco de operações relacionais (igual, diferente, maior, menor, maior ou igual, menor ou igual). Nós vamos comparar a nota. Vamos comparar se a nota é maior ou igual a 6. O que nós estamos dizendo é: se a nota for maior ou igual a 6, então entraremos no bloco "então" e exibiremos a mensagem "Você foi aprovado". Ou seja, se a nota digitada pelo usuário for maior ou igual a 6, a pessoa será aprovada e será exibida na tela a mensagem "Você foi aprovado".

E se a nota não for maior ou igual a 6? Se o usuário digitar um valor menor do que 6, por exemplo 5, nada acontece, porque a condição avalia se a nota é maior ou igual a 6. Só exibe a mensagem se for maior ou igual a 6. Para que nós possamos exibir uma mensagem caso a nota seja menor que 6, vamos utilizar o bloco "senão". O "senão" está dentro do próprio bloco "se". No editor do bloco, é necessário clicar na engrenagem para que a caixa de edição seja aberta. Agora nós temos a opção "senão". Arrastando o "senão" para dentro do bloco "se", podemos configurar: se a nota for maior ou igual a 6, faça isso (você foi aprovado); senão, ele vai fazer outra coisa. Vou copiar o bloco "imprimir" e colar, e agora vou mudar a mensagem para "Você foi reprovado". 

Então, se executarmos e digitarmos 7 (maior ou igual a 6), aparece "Você foi aprovado". Agora, se digitarmos um número menor que 6, por exemplo 3, aparece "Você foi reprovado". Esta é a estrutura "se" com a cláusula "senão".

Antes de passar por essas opções, vamos dar uma olhada no código gerado. Em Portugol, temos aqui a criação da variável "nota": "var nota". Em seguida, a nota é atribuída ao que está sendo chamado por "pergunte". O recurso chamado "função" converte o que o usuário tiver digitado para número. Se o usuário digitar 10, 3,5, 4, qualquer número, ele será convertido para uma representação interna de um número. Qualquer computador adota uma representação interna para números que não é a mesma representação de um texto. Aqui, a chamada da função "pergunte" vai exibir na tela a mensagem "Informe a nota", e o valor digitado será atribuído à variável.

Temos então a estrutura: "se (nota >= 6) { escreva("Você foi aprovado") } senao { escreva("Você foi reprovado") }". Observe que a estrutura "se" abre e fecha chaves. Isso é chamado de estrutura de bloco. A estrutura "se" trabalha com duas estruturas de bloco: uma para a cláusula "então" e outra para a cláusula "senão". Tudo o que estiver entre chaves será executado se a condição for atendida.

No caso do JavaScript, para exibir uma mensagem ou uma caixa de diálogo, é necessário criar uma função. Aqui está sendo utilizada a palavra-chave "function", sendo atribuído um nome para a função. É passado para essa função uma variável, que são as variáveis que mais utilizamos no programa. O que isso quer dizer? Que na hora que esta função for executada, ela vai receber um texto e trabalhar com ele. Então foi chamado o método "prompt". Todas as vezes que nós vemos uma palavra seguida de outra palavra, a primeira é a palavra-chave ou o nome do objeto, e a segunda é o método. Você pode considerar um método como uma função que executa um comando. Neste caso, ele executa "escreva" e exibe a mensagem. Esse fluxo é uma característica da linguagem. Em seguida é chamado o método "parseFloat", que converte o texto digitado para número decimal.

Veja como é feita a chamada dessa função: "prompt" e, dentro de parênteses, a mensagem que se quer exibir. Esqueci de comentar: esse "10" aqui é porque eu coloquei um valor padrão, mas vamos trabalhar com a base decimal.

Em JavaScript, novamente temos a criação da variável "nota", muito parecido com o que vimos em Portugol. Em seguida, "nota = parseFloat(prompt("Informe a nota"))". Só que, para exibir a caixa de diálogo, é chamado o método "prompt" do objeto "window". Lembra quando a gente tem o nome seguido de um ponto seguido de outro nome? O primeiro nome é o objeto, o segundo nome é o método. Neste caso, "window.prompt" envia a mensagem "Informe a nota". O usuário digita a nota, e essa nota vai ser então encaminhada para a estrutura "se": "if (nota >= 6) { window.alert("Você foi aprovado") } else { window.alert("Você foi reprovado") }".

Vejamos em MaiaScript. MaiaScript é um pouco mais simples: não é necessário declarar variáveis como "var". Temos "nota = parseFloat(prompt("Informe a nota"))". O objeto pré-definido "core" e dentro dele temos muitos métodos, muitas funções, muitos comandos. O "parseFloat" converte qualquer texto digitado para uma representação interna numérica. E para exibir a caixa de diálogo de entrada, chamamos o método "prompt" do objeto "core": "core.prompt("Informe a nota")". Em seguida, a declaração "se": "if (nota >= 6) { core.print("Você foi aprovado") } else { core.print("Você foi reprovado") }".

Em PHP, novamente temos a criação das variáveis. Lembra que a diferença básica é que colocamos o cifrão antes do nome da variável. A função "floatval" converte o dado para número, e a função "readline" lê o dado que o usuário digitou. Ele é convertido para número e atribuído à variável "$nota". Depois, "if ($nota >= 6) { echo "Você foi aprovado"; } else { echo "Você foi reprovado"; }".

Portugol já vimos. Vejamos Lua. Lua requer a definição de uma função. Nós temos "nota = nil" criando uma variável vazia. Em seguida, é criada uma função "testePrompt" que vai receber um valor e exibir na tela. Temos uma declaração especial do Lua que funciona para interceptar qualquer erro. Por exemplo, se acontecer algum erro durante a leitura do dado digitado pelo usuário, ele vai interceptar o erro e não vai parar o programa. Caso contrário, o programa pararia. Então, toda vez que é preciso tomar cuidado para que o programa não pare se ocorrer um erro, utilizamos essa declaração. Em seguida, retornamos o valor. A função recebe o dado digitado pelo usuário, e quando apertar Enter, vai ser atribuído à variável. O "nil" faz parte da declaração. Se ocorrer erro, ele coloca "nil" na variável e vai então executar o comando. Aqui nós temos novamente sendo atribuída à variável "nota" o texto digitado, chamando a função "testePrompt" e convertendo para número com "tonumber". Depois, a declaração "if nota >= 6 then print("Você foi aprovado") else print("Você foi reprovado") end".

Em Python, a estrutura é: "nota = float(input("Informe a nota"))" e depois "if nota >= 6: print("Você foi aprovado") else: print("Você foi reprovado")". Uma particularidade do Python é que não temos as chaves para delimitar o início e o fim. Em Python, a indentação (recuo) define o que pertence ao "if" e o que pertence ao "else". Tudo o que estiver recuado após os dois pontos faz parte daquele bloco.

Em Dart, a estrutura é semelhante ao JavaScript, com chaves delimitando os blocos. Em Java, também é com chaves. Cada linguagem tem suas particularidades, mas a lógica é a mesma: uma condição é avaliada e, dependendo do resultado, um bloco de código é executado.
