Nesta aula, aprenderemos a instalar as ferramentas necessárias para programar em C++. Utilizaremos o Visual Studio Code (VSCode) como nosso ambiente integrado de desenvolvimento, ou IDE. Uma IDE é um software que combina um editor de código, onde você pode escrever e editar seus programas, com um compilador.

O compilador é um programa fundamental. Ele converte o código que você digita, chamado de código fonte, em um programa executável. Esse executável é adaptado para uma arquitetura de computador e um sistema operacional específicos. Em outras palavras, o compilador pega o texto do seu programa e o transforma em um arquivo que o computador pode entender e executar diretamente.

Quando utilizamos ferramentes como o VisuAlg para criar algoritmos com blocos, não há necessidade de compilação, pois eles são executados imediatamente. No entanto, internamente, essas ferramentas até realizam uma compilação, mas geralmente para uma linguagem como o JavaScript para funcionar no navegador. Isso não gera um programa independente para o seu sistema operacional, como o Windows.

Para criar um programa nativo, como um executável com extensão `.exe` no Windows, precisamos de um compilador específico. Assim como um arquivo do Word tem a extensão `.docx` ou `.doc`, os programas executáveis têm extensões próprias. No Windows, a extensão mais comum é `.exe`. Em outros sistemas, como o Linux, os executáveis não têm uma extensão obrigatória; a capacidade de execução é definida por uma propriedade do arquivo.

O processo de compilação gera não apenas o programa em linguagem de máquina, que é a linguagem que o processador entende, mas também inclui uma série de outras informações essenciais para o sistema operacional. O sistema operacional é o software que gerencia todos os recursos do computador: memória, acesso a arquivos, segurança e todos os periféricos. Para que ele possa carregar e executar seu programa corretamente, o arquivo executável precisa conter instruções adicionais. Isso inclui, por exemplo, a posição inicial na memória de onde a execução deve começar, um mapa da memória que o programa vai utilizar, e outras informações de configuração.

Portanto, o compilador converte seu código fonte em um formato muito específico para uma dada arquitetura e sistema operacional, gerando o arquivo executável (como o `.exe`). É comum que o processo de compilação ocorra em vários estágios. Primeiro, o compilador pode transformar o código fonte em uma linguagem intermediária. Em seguida, essa linguagem intermediária é convertida para o código de máquina final. Há ainda a possibilidade de serem gerados outros artefatos, como os "objetos", mas isso foge um pouco do escopo da nossa disciplina. À medida que você avançar no curso de operador de computador e em sistemas operacionais, entenderá melhor o funcionamento desses elementos da arquitetura de um computador.

É muito importante ter em mente que o executável gerado é específico para uma arquitetura. Um programa compilado para Windows não roda nativamente no Linux, a menos que você utilize uma camada intermediária, uma camada de abstração. No Linux, existem projetos como o Wine, que criam uma camada de compatibilidade para rodar programas do Windows. Por outro lado, para rodar um programa feito para Linux no Windows, você precisaria recompilar o código fonte dentro de um ambiente que simule o Linux, como o WSL (Windows Subsystem for Linux). É uma história um pouco mais complexa que envolve recompilação e adaptação.

No caso do Windows, um dos compiladores mais comuns é o do Visual Studio, da Microsoft. Existe também uma versão do compilador C/C++ adaptada para o Windows, conhecida como MinGW (Minimalist GNU for Windows). O MinGW permite compilar programas para Windows usando código fonte escrito para sistemas GNU/Linux, mas ele é uma ferramenta de linha de comando. Isso significa que, para usá-lo, você precisaria abrir o prompt de comando e digitar instruções manualmente. Para facilitar, utilizaremos o Visual Studio Code, que nos dá um editor de texto avançado e, com extensões apropriadas, integra o compilador de forma mais amigável.

O VSCode é um editor de código-fonte desenvolvido pela Microsoft. Ele é gratuito, de código aberto e suporta diversas linguagens de programação por meio de extensões. Para programar em C++, você precisará instalar o compilador (como o MinGW) e, em seguida, configurar o VSCode para utilizá-lo. O VSCode não vem com um compilador embutido, mas permite que você integre um facilmente. Isso dá a flexibilidade de escolher o compilador que preferir e ter um ambiente de desenvolvimento moderno e altamente personalizável.

Ao abrir o VSCode pela primeira vez, você verá uma tela de boas-vindas. Você pode criar um novo arquivo e salvá-lo com a extensão `.cpp` (por exemplo, `meu_programa.cpp`) para começar a escrever seu código. O editor oferece funcionalidades como realce de sintaxe, autocompletar e sugestões enquanto você digita, o que ajuda a evitar erros comuns de digitação e acelera o aprendizado.

Para compilar e executar seu programa, você pode utilizar o terminal integrado do VSCode. Com o arquivo `.cpp` salvo, você pode abrir o terminal, navegar até a pasta onde o arquivo está e digitar o comando de compilação. Por exemplo, usando o compilador `g++` do MinGW, o comando seria `g++ meu_programa.cpp -o meu_programa.exe`. Isso gerará o executável. Para executá-lo, basta digitar `./meu_programa.exe` no terminal.

Faremos um teste simples. Criaremos um novo arquivo, digitaremos um pequeno programa e o compilaremos para ver tudo funcionando. Este será nosso primeiro contato prático com o processo de escrita, compilação e execução de um programa em C++.
