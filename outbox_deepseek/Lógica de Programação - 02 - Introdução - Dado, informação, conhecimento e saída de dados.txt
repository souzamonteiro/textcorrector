Olá! Nesta aula, aprenderemos como funciona a ferramenta Learning Blockly e entenderemos o que são dados, informações e conhecimento, além de como apresentar dados na tela.

Esta é a ferramenta Learning Blockly. Ela foi desenvolvida por mim para o projeto Maia. O projeto Maia consiste em uma linguagem de programação. Esta linguagem é orientada a objetos, ou seja, ela permite o desenvolvimento de aplicações utilizando o paradigma da orientação a objetos. Foi desenvolvida especificamente para a construção de aplicações científicas, mas pode ser utilizada para a construção de qualquer aplicação de uso geral.

Para acessar a ferramenta Learning Blockly, pode-se clicar em Projetos, Acesso Público, e em Learning Blockly. Caso queira ter acesso à área restrita do projeto, para ter acesso às versões beta do Learning Blockly, basta clicar em Acesso Restrito. Lá, algumas pessoas recebem acesso a esta versão porque ela está em desenvolvimento. A versão atual é a disponível publicamente. Também é possível acessar digitando diretamente o endereço: maiascript.com.br/learningblockly.

A ferramenta foi desenvolvida utilizando a biblioteca do Blockly, do Google, que criou esta biblioteca para que se pudesse desenvolver uma versão mais confortável e mais fácil de manter de uma linguagem de programação chamada Blockly. O Google liberou a biblioteca publicamente, e os desenvolvedores a utilizaram para construir aplicações como esta, que permitem a programação a partir de blocos. Muitos usam para outras finalidades, mas nós utilizamos aqui para a programação a partir de blocos.

A ferramenta pode ser utilizada em alguns idiomas. No nosso caso, vamos selecionar o português. Os blocos que vão para o topo são os acessíveis da mente lógica, o restante dos blocos de operações lógicas que veremos mais adiante. Em Laços, podemos acessar os blocos de laços de repetição. Em Matemática, estão os blocos aritméticos. Em Texto, pode-se acessar os blocos para operações com textos de diversos tipos. Em Listas, podemos acessar blocos para operações com listas ou vetores. Em Cores, que não utilizaremos neste curso, são permitidas algumas operações com cores. Em Variáveis, criamos as variáveis que aprenderemos mais adiante. E em Funções, podemos criar novas funções ou utilizar funções que já temos criado nos programas, que vão ficar disponíveis aqui na forma de blocos.

A área de trabalho do Learning Blockly está dividida em quatro partes: a barra superior, onde estão os comandos; a área central, onde nós temos a palheta de blocos e a tela onde podemos desenhar os programas a partir da paleta de blocos; a primeira área de código, onde veremos os blocos que forem desenhados nesta área convertidos para o código na linguagem de programação que escolhermos; e a segunda área de código, onde veremos os blocos tendo sido convertidos para o código de programação na segunda linguagem de programação que escolhermos.

Neste caso, temos escolhido aqui MaiaScript, mas é possível também selecionar Dart, JavaScript, Lua, MaiaScript, PHP, Portugol e Python. Na segunda área, também temos as mesmas linguagens que podemos selecionar.

Vamos agora criar nosso primeiro programa, chamado "Alô, Mundo!", o programa que é sempre criado em qualquer linguagem de programação. Para tanto, clicamos em Texto, descemos para o bloco "imprimir" e o arrastamos para a área. O bloco "imprimir" permite que você digite um texto diretamente logo após o comando, mas também é possível buscar um bloco de aspas e colocá-lo conectado, e então escrever o texto que desejamos aqui dentro. Esse bloco é utilizado quando se deseja apenas apresentar um texto na tela. Então, posso tanto digitar aqui "Alô, Mundo!" quanto eu posso remover o bloco, digitar aqui "Alô", colocar o bloco de texto e depois "Mundo". Funcionará do mesmo jeito. Neste caso, eu vou deixar o bloco e utilizar a forma escrevendo o texto logo após o comando.

Todo bloco colocado nesta área passa a ser um comando em uma das linguagens de programação selecionada. Veja que, como na primeira área de código está selecionado MaiaScript, aparece um código correspondente ao comando na linguagem MaiaScript. Na segunda área de código, está selecionada a linguagem Portugol, e então é exibido um código correspondente à linguagem Portugol, que nada mais é que uma linguagem de programação em português.

Se quisermos executar este código, basta clicar no botão "Executar", este que parece uma seta. Clicando, é exibida uma caixa escrito "Alô, Mundo!".

Observe que tudo o que é exibido na tela é dado ou informação. Dado é qualquer conteúdo bruto que não tenha sido processado, que não tenha recebido um significado especial. A informação, por outro lado, é o dado convertido em algo especial, algo que tenha valor. A partir das informações adquiridas, os seres humanos constroem conhecimento. Então, nós temos três elementos: dado, informação e conhecimento.

Neste caso, o dado que estamos trabalhando é a expressão "Alô, Mundo!". Ao clicarmos em "Executar", o comando "imprimir" exibiu o dado "Alô, Mundo!". Se, ao invés de um texto, tivéssemos uma expressão matemática, essa expressão matemática trabalharia em cima de dados e produziria informação, que seria o resultado da expressão matemática sendo resolvida.

Copie todo o código que foi gerado na área de código. Ele é compatível com a linguagem de programação selecionada e funcionará perfeitamente no ambiente de programação da linguagem selecionado. Se selecionar o texto da área e copiar o MaiaScript, vamos testar no MaiaStudio, o ambiente de programação da linguagem MaiaScript. É só colar e executar. Veja que funcionou perfeitamente.

Também posso fazer o mesmo no console do MaiaScript. Executar aqui. Neste caso, não foi exibido na tela porque o console não mostra saídas padrão. A gente precisa executar o programa para que ele funcione.

Voltando, se fosse um comando de operações aritméticas, por exemplo, "1 + 2", nós executaríamos aqui e ele exibiria a saída em uma caixa. Mas vejamos: se selecionarmos ao lado Dart, que é uma linguagem de programação desenvolvida pelo Google, nós veremos o código correspondente. Observe que o código é um pouco mais complexo, mas temos a expressão "main" em seguida de parênteses, abre chaves, um comando "print" com "Alô, Mundo!" terminando com ponto e vírgula, e fechando com chave. Todo programa em Dart tem o que a gente chama de função "main" seguida de comandos dentro da declaração da função. Toda função "main" em Dart terá que começar com chaves e terminará com chave. Tudo o que estiver entre chaves são comandos que serão executados. Então, aqui nós temos o programa "Alô, Mundo!" convertido para Dart.

Se quisermos ver o programa em JavaScript, ele simplesmente será o comando "alert" com "Alô, Mundo!". No JavaScript, chamamos uma coisa que nós chamamos de objeto: objeto "window" com o método "alert". Se quisermos ver o mesmo comando em PHP, o comando se torna "echo" "Alô, Mundo!" terminado com ponto e vírgula, pois nas linguagens JavaScript, PHP e outras, o ponto e vírgula é sempre necessário no final do comando. Em Portugol, nós já vimos: "escreva" "Alô, Mundo!". E em Python, é "print" ("Alô, Mundo!").
