Nossa aula agora aborda os fundamentos e elementos básicos de um programa em C. Todo problema em programação se resume a um conjunto de instruções que começam com um exemplo de diretiva de pré-processamento. Toda diretiva de pré-processamento começa com o caractere #, que é chamado de sustenido. Esse caractere é usado para indicar ao compilador que uma diretiva está sendo usada.  

A diretiva #include é usada para incluir bibliotecas no programa. Por exemplo, para incluir a biblioteca padrão de entrada e saída, usamos `#include <stdio.h>`. Essa diretiva é processada antes do programa ser compilado. O pré-processador busca e inclui os arquivos necessários no programa.  

Todo programa em C começa com a função `main()`, que é a função principal do programa. A função `main()` tem um tipo de retorno, geralmente `int`, e é responsável por executar as instruções do programa.  

A estrutura básica de um programa em C inclui:  
1. Diretivas de pré-processamento (como `#include`).  
2. A função `main()`, que contém as instruções do programa.  
3. A função `printf()` para exibir mensagens na tela.  
4. A função `return` para encerrar o programa e retornar um valor.  

Por exemplo, o programa "Hello World" em C é escrito da seguinte forma:  
```c
#include <stdio.h>
int main() {
    printf("Hello, World!\n");
    return 0;
}
```  
Nesse programa, a função `printf()` exibe a mensagem "Hello, World!" na tela, e a função `return 0;` indica que o programa terminou com sucesso.
