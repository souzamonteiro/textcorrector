Aula sobre Estruturas de Repetição  
Nesta aula, aprenderemos sobre estruturas de repetição, que permitem executar porções de código repetidamente enquanto uma condição é avaliada como verdadeira ou até que uma condição seja verdadeira. Utilizaremos os blocos `repita enquanto` e `repita até`.  

**Bloco `repita enquanto`**  
Para utilizar o bloco `repita enquanto`, definimos uma variável, por exemplo, `n`. Inicializamos essa variável com um valor, como `0`, e definimos uma condição. Por exemplo, compararemos `n` com o valor `5`. A estrutura ficará assim:  
```  
repita enquanto n < 5  
```  
Dentro do bloco, a porção de código será executada repetidamente enquanto a condição for verdadeira. Para que isso aconteça, o valor de `n` deve ser modificado durante a execução. Por exemplo, incrementamos `n` em `1` a cada iteração.  

**Exemplo de Execução**  
Vamos ver como funciona:  
1. Inicializamos `n = 0`.  
2. Executamos o bloco: exibimos o valor de `n`, incrementamos em `1` e retornamos ao início do laço.  
3. O processo se repete até que `n` atinja `5`, momento em que a condição se torna falsa e o laço termina.  

**Bloco `repita até`**  
O bloco `repita até` funciona de forma oposta: o laço executa enquanto a condição é falsa e para quando a condição se torna verdadeira. Por exemplo:  
```  
repita até n > 5  
```  
Neste caso, o laço continua enquanto `n` for menor ou igual a `5`, e para quando `n` ultrapassar `5`.  

**Estrutura `contar` (for)**  
Outra forma de repetição é a estrutura `contar`, que controla a variável de iteração automaticamente. Por exemplo:  
```  
contar de 1 até 10 passo 1  
```  
Essa estrutura define um valor inicial, uma condição de parada e um incremento. Em linguagens como Lua, JavaScript e PHP, a sintaxe varia, mas o conceito é similar.  

**Exemplos em Diferentes Linguagens**  
- **Lua**:  
  ```lua  
  for i = 1, 10, 1 do  
    print(i)  
  end  
  ```  
- **JavaScript**:  
  ```javascript  
  for (let i = 1; i <= 10; i += 1) {  
    console.log(i);  
  }  
  ```  
- **PHP**:  
  ```php  
  for ($i = 1; $i <= 10; $i += 1) {  
    echo $i;  
  }  
  ```  

**Conclusão**  
As estruturas de repetição são fundamentais para automatizar tarefas em programação. Cada tipo de laço (`repita enquanto`, `repita até` e `contar`) tem suas particularidades, e a escolha depende da lógica do problema. Compreender essas estruturas permite escrever código mais eficiente e organizado.
