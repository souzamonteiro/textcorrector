**Aula: Vetores de Caracteres e Ponteiros**  

Nesta aula, aprenderemos sobre vetores de caracteres e como utilizar ponteiros. Vamos aproveitar o esqueleto de um programa para explorar o tema.  

Um vetor de caracteres é um espaço de memória que funciona como uma matriz, mas com a diferença de armazenar caracteres em vez de números. Em C, um vetor de caracteres é chamado de *string* (cadeia de caracteres). Para trabalhar com vetores, é comum utilizar ponteiros, que são variáveis que armazenam endereços de memória.  

Vamos criar um vetor chamado `texto` com tamanho fixo, por exemplo, 20 caracteres. Podemos acessar qualquer posição do vetor utilizando um índice, que é uma variável de controle. Por exemplo:  

```c
char texto[20];
```

Para permitir que o usuário digite uma expressão, utilizamos a função `scanf` ou `fgets` para ler a entrada. Por exemplo:  

```c
printf("Digite uma expressão: ");
fgets(texto, 20, stdin);
```

Ao exibir o conteúdo do vetor, podemos utilizar um loop para percorrer cada posição e imprimir um caractere por linha.  

### Exemplo: Exibição de um Vetor de Caracteres  
```c
for (int i = 0; i < 20; i++) {
    printf("%c\n", texto[i]);
}
```

### Ponteiros e Manipulação de Vetores  
Ponteiros são úteis para manipular vetores, pois permitem acessar e modificar posições específicas da memória. Por exemplo:  

```c
char *p = texto;  // p aponta para o início do vetor
```

Podemos utilizar a aritmética de ponteiros para mover o ponteiro para a próxima posição:  

```c
p++;
printf("%c\n", *p);  // Exibe o segundo caractere
```

### Funções para Manipulação de Strings  
Além de utilizar ponteiros, podemos usar funções da biblioteca `string.h`, como `strlen` (para obter o tamanho da string) e `strcpy` (para copiar strings). Por exemplo:  

```c
int tamanho = strlen(texto);
strcpy(destino, texto);
```

### Exemplo: Função para Converter Texto para Maiúsculas  
Vamos criar uma função que converte uma string para maiúsculas:  

```c
void paraMaiuscula(char *origem, char *destino) {
    while (*origem != '\0') {
        *destino = toupper(*origem);
        origem++;
        destino++;
    }
    *destino = '\0';  // Adiciona o caractere de terminação
}
```

### Memória e Alocação  
Variáveis locais em funções são alocadas na *pilha* (stack), que é automaticamente liberada quando a função termina. Para alocação dinâmica, utilizamos `malloc` e `free`.
