Olá! Nesta aula, aprenderemos sobre funções e procedimentos. Funções e procedimentos são rotinas que contêm fragmentos de código que podem ser executados sem repetir a escrita do código. Essencialmente, elas atuam como agentes que podem ser chamados a partir do seu nome. Vamos explorar como criar funções e procedimentos no ambiente de blocos.  

Acessamos a paleta de funções e encontramos duas opções: a primeira refere-se a **procedimentos**, e a segunda, a **funções**. Vamos criar inicialmente um **procedimento**. Observe o bloco para esse procedimento. Vamos escrever o nome do procedimento, chamando-o de `direCalor`. É comum utilizar nomes em letras minúsculas para procedimentos, pois o ambiente de blocos permite isso, embora, em linguagens de programação, isso não seja suportado.  

No ambiente de blocos, nomes de variáveis e procedimentos podem conter letras minúsculas, sinais de pontuação, números (mas não podem começar com números) e caracteres como `_`. Por exemplo, nomes como `mundo`, `croácia` ou `sinal_de_igual` são válidos.  

Agora, vamos criar um bloco de um procedimento que, ao ser chamado, exiba a mensagem "Olá, mundo!". Para isso, clicamos no bloco de texto e escrevemos a mensagem. Em seguida, utilizamos esse procedimento: ao criar um procedimento, ele aparece na paleta de funções e procedimentos, e basta chamá-lo ao clicar no bloco correspondente.  

Vamos ver como isso se traduz em linguagens de programação:  
- **JavaScript**:  
  ```javascript  
  function direCalor() {  
    window.alert("Olá, mundo!");  
  }  
  ```  
  Para chamar a função, utilizamos `direCalor();`.  

- **PHP**:  
  ```php  
  function direCalor() {  
    echo "Olá, mundo!";  
  }  
  ```  
  Chamamos a função com `direCalor();`.  

- **Lua**:  
  ```lua  
  function direCalor()  
    print("Olá, mundo!")  
  end  
  ```  
  Chamamos a função com `direCalor()`.  

Agora, vamos explorar **parâmetros**. Um procedimento pode receber valores externos. Por exemplo, se criarmos um procedimento que exibe um nome, passamos o parâmetro `nome` como entrada.  
- **JavaScript**:  
  ```javascript  
  function saudacao(nome) {  
    alert("Olá, " + nome + "!");  
  }  
  ```  
  Chamamos a função com `saudacao("João");`.  

- **PHP**:  
  ```php  
  function saudacao($nome) {  
    echo "Olá, $nome!";  
  }  
  ```  
  Chamamos a função com `saudacao("João");`.  

- **Lua**:  
  ```lua  
  function saudacao(nome)  
    print("Olá, " .. nome .. "!")  
  end  
  ```  
  Chamamos a função com `saudacao("João")`.  

Para **funções**, que retornam valores, o processo é semelhante. Por exemplo, uma função que soma dois números:  
- **JavaScript**:  
  ```javascript  
  function soma(x, y) {  
    return x + y;  
  }  
  ```  
  Chamamos a função com `soma(2, 3);`, resultando em `5`.  

- **PHP**:  
  ```php  
  function soma($x, $y) {  
    return $x + $y;  
  }  
  ```  
  Chamamos a função com `soma(2, 3);`.  

- **Lua**:  
  ```lua  
  function soma(x, y)  
    return x + y  
  end  
  ```  
  Chamamos a função com `soma(2, 3)`.  

Resumindo:  
- **Procedimentos** são blocos de código que executam ações, mas não retornam valores.  
- **Funções** são semelhantes aos procedimentos, mas retornam valores.  
- Parâmetros são valores passados para funções ou procedimentos, permitindo maior flexibilidade.  

Com esses conceitos, você pode criar e utilizar funções e procedimentos de forma eficiente em qualquer linguagem de programação!
