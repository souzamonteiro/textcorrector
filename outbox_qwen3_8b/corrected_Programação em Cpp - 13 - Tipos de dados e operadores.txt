Nesta aula, aprenderemos sobre tipos de dados, operadores e variáveis. Na aula anterior, mostrei os elementos básicos de uma estrutura de programas, mas, para dar continuidade, vamos abordar o quarto ponto: tipos de dados.  

Vamos começar com os conceitos fundamentais. Em programação, as variáveis são usadas para armazenar dados, e cada tipo de dado define o tipo de informação que pode ser armazenado. Por exemplo, se quero armazenar apenas um caractere, uso o tipo `char`. Se quiser armazenar uma sequência de caracteres, utilizo uma cadeia de caracteres (`string`).  

Para ilustrar, vamos criar variáveis. Se quero armazenar um único caractere, como "a", utilizo aspas simples:  
```c  
char letra = 'a';  
```  
Se quiser armazenar uma frase, como "Olá, mundo!", uso aspas duplas:  
```c  
string frase = "Olá, mundo!";  
```  

Além disso, existem outros tipos de dados, como números inteiros (`int`) e números flutuantes (`float`). Por exemplo:  
```c  
int idade = 25;  
float altura = 1.75;  
```  

Agora, vamos falar sobre operadores. Eles são usados para realizar operações com variáveis. Os principais tipos são:  
1. **Operadores aritméticos**: `+`, `-`, `*`, `/`, `%` (resto da divisão).  
2. **Operadores relacionais**: `==`, `!=`, `>`, `<`, `>=`, `<=`.  
3. **Operadores lógicos**: `&&` (e), `||` (ou), `!` (não).  

Por exemplo, para comparar dois valores:  
```c  
if (idade > 18) {  
    printf("Maior de idade");  
}  
```  

Também é importante entender como atribuir valores às variáveis. Utilizamos o operador de atribuição (`=`) para isso:  
```c  
idade = 30;  
```  

Ao trabalhar com entradas de dados, como a idade ou altura de uma pessoa, usamos funções de entrada, como `scanf` em C. Por exemplo:  
```c  
printf("Informe sua idade: ");  
scanf("%d", &idade);  
```  

Além disso, é fundamental entender a diferença entre variáveis de tipos diferentes. Por exemplo, um `int` armazena números inteiros, enquanto um `float` armazena números com casas decimais. Essa diferença afeta a precisão e o tamanho dos dados.  

Por fim, os operadores lógicos são usados para combinar condições. Por exemplo:  
```c  
if (idade >= 18 && idade <= 60) {  
    printf("Idade válida");  
}  
```
