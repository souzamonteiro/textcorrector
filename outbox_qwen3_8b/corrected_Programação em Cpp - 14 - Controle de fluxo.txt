Nesta aula, aprenderemos sobre controle de fluxo na linguagem de programação. Na aula passada, falamos sobre operadores lógicos, e hoje abordaremos como usar esses operadores para controlar o fluxo de um programa. Controlar o fluxo é essencial para que o código execute ações específicas com base em condições avaliadas como verdadeiras ou falsas.  

Vamos criar uma estrutura condicional, como o `if` e o `else`, para que o código execute determinadas ações apenas quando uma condição for atendida. Por exemplo, podemos verificar a idade de uma pessoa e exibir uma mensagem diferente dependendo do resultado. Um exemplo prático seria:  

```javascript
let idade = 18;
if (idade >= 18) {
  console.log("Você tem 18 anos ou mais.");
} else {
  console.log("Você tem menos de 18 anos.");
}
```  

Além disso, existem estruturas como o `switch`, que permite comparar um valor com múltiplas opções. Por exemplo, para verificar o gênero de uma pessoa:  

```javascript
let genero = "masculino";
switch (genero) {
  case "masculino":
    console.log("Você é do gênero masculino.");
    break;
  case "feminino":
    console.log("Você é do gênero feminino.");
    break;
  default:
    console.log("Gênero indefinido.");
}
```  

Outra estrutura importante é o loop `while`, que executa um bloco de código enquanto uma condição for verdadeira:  

```javascript
let contador = 0;
while (contador < 5) {
  console.log(contador);
  contador++;
}
```  

Já o loop `for` combina inicialização, condição e incremento em uma única linha:  

```javascript
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```  

Por fim, é importante mencionar como lidar com variáveis e tipos de dados. Por exemplo, podemos comparar caracteres ou números, e a linguagem permite realizar operações matemáticas com variáveis, mesmo que seu conteúdo seja um caractere.  

Essas estruturas são fundamentais para criar programas dinâmicos e eficientes, permitindo que o código adapte seu comportamento com base em diferentes condições.
