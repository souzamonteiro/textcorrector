**Aula: Estruturas Homogêneas (Vetores)**  

Nesta aula, aprenderemos sobre **estruturas homogêneas**, também conhecidas como vetores. Essas estruturas permitem armazenar valores de diversos tipos, como números, strings e até objetos complexos. A maioria das linguagens de programação suporta essa funcionalidade.  

### Criando uma Lista  
Para trabalhar com listas ou vetores, utilizamos a seção "Lista", a paleta de listas e os blocos "Criar Lista", "Definir" e "Obter Elemento".  

1. **Criar uma variável chamada `nota`** para armazenar as notas digitadas pelo usuário.  
2. **Transformar a variável `nota` em uma lista**:  
   - Utilize o bloco "Criar Lista".  
   - O bloco possui três posições por padrão, mas pode ser expandido conforme necessário.  
   - Para adicionar elementos, arraste o bloco de "Item" para a posição desejada.  

3. **Iniciar os elementos da lista**:  
   - Para uma lista de números, utilize o bloco numérico.  
   - Exemplo: `criar lista [0, 1, 2]`.  

### Percorrendo os Elementos da Lista  
Para acessar cada elemento da lista, utilizamos um **laço de repetição**.  
- O bloco "Contar" será usado para iterar sobre os elementos da lista.  
- A variável de controle (por exemplo, `i`) assume valores de 1 até o tamanho da lista.  
- A posição dos elementos na lista é numerada a partir da primeira posição (1, 2, 3, etc.).  

**Exemplo**:  
```  
para i de 1 até 3:  
    obter elemento da lista `nota` na posição i  
    exibir "Nota " + i + ": " + elemento  
```  

### Solicitando Digitação do Usuário  
Para coletar notas do usuário:  
1. Utilize o bloco "Criar Texto" para exibir uma mensagem solicitando a entrada.  
   - Exemplo: `"Digite a nota da posição " + i + ": "`.  
2. Converta a entrada do usuário para um número utilizando a função `parseFloat` (JavaScript) ou `float` (PHP).  
3. Armazene o valor na posição correspondente da lista.  

### Exemplo em JavaScript  
```javascript  
let notas = [];  
for (let i = 1; i <= 3; i++) {  
    let entrada = parseFloat(prompt("Digite a nota da posição " + i + ": "));  
    notas[i - 1] = entrada;  
}  
```  

### Exemplo em PHP  
```php  
$notas = [];  
for ($i = 1; $i <= 3; $i++) {  
    $entrada = floatval($_GET["nota$i"]);  
    $notas[$i - 1] = $entrada;  
}  
```  

### Exemplo em Lua  
```lua  
notas = {}  
for i = 1, 3 do  
    print("Digite a nota da posição " .. i .. ": ")  
    notas[i] = tonumber(io.read())  
end  
```  

### Conclusão  
- Vetores (listas) são estruturas fundamentais para armazenar e manipular coleções de dados.  
- A indexação começa em 0 em linguagens como JavaScript e PHP, enquanto em outras (como Lua) começa em 1.  
- A conversão de entrada do usuário para números é essencial para operações matemáticas.  
- A utilização de laços de repetição permite acessar e processar cada elemento da lista de forma eficiente.
