Olá nesta aula aprenderemos como funciona a ferramenta LearningBlockly, entenderemos o que são dados, informações e conhecimentos e como apresentar dados na tela.
Esta é a ferramenta LearningBlockly. Ela foi desenvolvida por mim para o projeto MaiaScript. O projeto MaiaScript consiste uma linguagem de programação. Esta linguagem objeto orientada, ou seja ela permite o desenvolvimento de aplicações utilizando o paradigma da orientação a objetos e foi desenvolvida especificamente para a construção de aplicações científicas. Mas pode ser utilizada para construção de qualquer aplicação de uso geral.
Para acessar a ferramenta desenvolvimento LearningBlockly, pode-se clicar em projetos, acesso público, LearningBlocly, ou caso se tena acesso a área restrita do projeto aonde se pode acessar as versões beta do LearningBlocly, basta clicar em acesso restrito, LearningBlockly. Mas somente algumas pessoas recebem acesso a esta versão porque ela está em desenvolvimento. A versão atual é disponível em acesso público, LearningBlocly. Também é possível selecionar digitando diretamente o endereço https://www.maiascript.com/learningblockly.
A ferramenta foi desenvolvida utilizando a biblioteca blockly do google, que criou esta biblioteca para que se pudesse desenvolver uma versão mais portável e mais fácil de manter de uma linguagem de programação chamada Scratch do MIT. Mas ele liberou a biblioteca publicamente e de desenvolvedores que a utilizam para construir aplicações com essa que permitem a programação a partir de blocos. Muitos usam para outras finalidades. Nós utilizamos aqui a programação a partir de blocos.
A ferramenta pode ser utilizada em alguns idiomas. No nosso caso vamos selecionar o português.
Nos menus são acessíveis os blocos de lógica, com os blocos de operações lógicas que veríamos bem adiante; laços, para acessar os blocos de rua laços de repetição; matemática, onde estão os blocos aritméticos; texto, onde se pode acessar os blocos para operações com textos de diversos tipos; listas, onde podemos acessar blocos para operações com listas ou vetores; cor, que não utilizaremos neste curso, mas que permitem algumas operações com cores; variáveis, onde criamos as variáveis que aprenderemos mais adiante; e funções, onde podemos criar novas funções ou utilizar funções que já tenhamos criado no nosso programa e que vão ficar disponíveis aqui na forma de blocos.
A área de trabalho do LearningBlockly está dividida em quatro partes: a barra superior onde estão os comandos comuns; a área central onde nós temos a palheta onde podemos desenhar os objetos a partir da paleta de objetos; a primeira área de código onde veremos os blocos que serão desenhados nesta área como um código na linguagem de programação que escolhermos e a segunda área de código code veremos os blocos tendo sido convertidos para o código de programação na segunda linguagens de programação que escolhemos. Nste caso escolhemos aqui MaiaScript, mas é possível também selecionar Dart, JavaScript, Lua, MaiaScript, PHP, Portugol e Python e na segunda também temos as mesmas línguas que podemos selecionar.
Vamos agora criar nosso primeiro programa chamado "Alô Mundo!". O programa que é sempre criada em qualquer linguagem de programação é o "Alô Mundo!". Para tanto, clicamos em texto; descemos para imprime e arrastamos o bloco para a área de trabalho. O bloco imprime permite que você digite um texto diretamente logo após ele, mas também é possível buscar um bloco de aspas e colocar conectado a ele e escrever o texto que desejávamos aqui dentro. Esse bloco quando se deseja apenas apresentaram texto é opcional. Então eu posso tanto digitar aqui "Alô Mundo!", quanto eu posso remover o bloco e digitar aqui "Alô Mundo!", que funcionará do mesmo jeito. Neste caso vou deletar o bloco e utilizar a forma escrevendo texto logo após o comando imprime.
Todo bloco colocado nesta área passa ser um comando em uma das linguagens de programação selecionada. Veja que como na primeira área de código está selecionado MaiaScript, apareceu um código correspondente ao executado na linguagem MaiaScript. Na segunda área de código está selecionada linguagem Portugol e foi então exibir um código correspondente à linguagem Portugol, que nada mais é que uma linguagem de programação em português
Se quisermos executar este código basta clicar no botão executar. Este que parece uma seta. Clicando, será exibida uma caixa escrito "Alô Mundo!".
Observe que tudo o que é exibido na tela é dado ou informação. Dado é qualquer conteúdo bruto que não tenha sido processado, que não tenha recebido um significado especial. Já a informação, por outro lado, é o dado convertido em algo especial, algo que tenha valor. A partir de muitas informações adquiridas, os seres humanos constroem conhecimento. Então nós temos três elementos: dado, informação e conhecimento. Neste caso o dado que estamos trabalhando é a expressão "Alô Mundo!". Ao clicarmos em executar, o comando imprime exibiu dado "Alô Mundo!". Se ao invés de um texto tivéssemos uma expressa matemática, essa expressão matemática trabalharia em cima de dados produziriam uma informação que seria o resultado da expressão matemática sendo resolvida.
Todo o código que foi gerado na área de de código ele é compatível com a linguagem de programação selecionada e funcionará perfeitamente no ambiente de programação da línguas selecionado. Vamos selecionar o texto do código em MaiaScript e vamos testar no MaiaStudio, o ambiente de programação da linguagem MaiaScript, colar e executar. Veja que funcionou perfeitamente. Também posso fazer o mesmo no console do MaiaStudio e executar. Neste caso não foi exibido na tela por que o console não mostra saídas em caixas de diálogo, e a gente precisa clicar no botão aqui em cima para que ele funcione.
Voltando para cá. Se fosse um comando de operações aritméticas, por exemplo, um mais dois estaremos postando aqui. Mas como a saída é em uma caixa ele não exibiu aqui na tela.
Mas vejamos, se selecionarmos ao invés de MaiaScript, Dart, que é uma linguagem de programação desenvolvida pelo Google, nós veremos o código correspondente.
Observe que o código um pouco mais complexo: nós temos a expressão main, seguida de parênteses, abre chaves; um comando print "Alô Mundo!", terminando com ponto e vírgula e fechando com chaves.
Todo o programa em Dart tem essa aparência. Ele tem uma função, que a gente chama de função main, seguido de comandos dentro da declaração da função. Toda função em Dart, começará com chaves e terminará com chaves. E tudo o que estiver entre chaves são comandos que serão executados. Então aqui nós temos o programa imprime "Alô Mundo!" convertido para Dart.
Se quisermos ver o programa em JavaScript, ele simplesmente será o comando alert "Alô Mundo!". Para executar o comando alert, nós chamamos uma coisa que nós chamamos de objetos: objeto window.alert "Alô Mundo!". Se quisermos ver o mesmo comando em Lua o comando se torna print "Alô Mundo!". Se quisermos ver em PHP também será print "Alô Mundo!", mas terminado com ponto e vírgula, pois nas linguagens JavaScript, PHP e algumas outras, o ponto e vírgula sempre necessário final de um comando. Em portugal nós já vimos: escreva "Alô Mundo!" e Python, que é print "Alô Mundo!".
