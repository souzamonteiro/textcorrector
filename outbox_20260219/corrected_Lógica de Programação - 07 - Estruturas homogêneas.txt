Olá, nesta aula aprenderemos sobre estruturas homogêneas. Estruturas homogêneas são vetores, no qual podemos armazenar valores de diversos tipos. A maioria das linguagens de programação permite que se armazene números, strings e até objetos complexos. Neste curso, nós iremos armazenar um especificamente, números. Para trabalhar com listas ou vetores, utilizamos a seção lista, a paleta de listas e os blocos "criar lista", "definir" e "obter um elemento de vista". Vamos criar uma variável chamada "nota" e vamos utilizar essa variável para solicitar a digitação de notas pelo usuário. "Nota definir nota". Para criar uma lista para transformar a variável "nota" em uma lista, utilizaremos o bloco "criar lista". Com o bloco, temos três posições por padrão, mas podemos acrescentar qualquer quantidade de posições que desejarmos. Se simplesmente arrastamos do bloco de item, abaixamos para a quarta posição da lista. Caso deixemos somente três, para inicializar os elementos da lista, utilizaremos neste caso, já que uma lista de números, o bloco numérico. Vou colocar os valores um, dois e três. Criamos uma lista para percorrer os elementos desta lista. Já que a lista "nota" possui três posições, nós vamos utilizar um laço de repetição "comprar". Com este laço, contar quantos elementos temos. Podemos criar outras variáveis se desejarmos. Quando utilizamos o "comprar", a variável "contador" é padrão e as variáveis podem ser criadas. Quando utilizamos o "comprar", as palavras-chave são números entre um e dez por padrão, mas nossa lista só tem três posições. Vamos alterar a posição para três para que nós possamos preencher cada um dos elementos da lista. Vamos utilizar o bloco "definir lista" e vamos colocar na posição, logo, a seguir a palavra "número" e a variável "i". Usaremos os valores um, dois e três. Este é o elemento na posição "i". Para acessar os elementos desta lista, utilizamos o bloco "colchete" e a variável "i". Observe que em "comprar", a primeira posição não é a posição zero, por isso fazemos a conta começando em um, dois e três. Quando este contador é menor que zero, igualizamos com zero. Quando o contador é igual a zero, o laço termina. Para solicitar a digitação, utilizamos o método "input" do objeto "print". Não é necessário fazer nenhuma operação de vetor, porque o "input" já tem essa função. O método "input" recebe uma string que solicita os dados. Para exibir a caixa de diálogo solicitando os dados, utilizamos o método "show" do objeto "print". Este método não é necessário fazer nenhuma operação de vetor porque o "input" já tem essa função. Vamos agora percorrer esta lista mostrando os valores na tela. Vou duplicar o bloco "contar" e remover estes blocos. Agora vou utilizar o bloco "imprimir" para mostrar os valores da tela. Vamos criar um texto comum. Vamos colocar uma string que diz "nota:". Após o texto, colocamos um espaço. Em seguida, colocamos o bloco "obter" para obter o valor da lista. Selecionamos a nossa lista "nota" e colocamos aqui. O valor da lista na posição "i". Vamos mostrar o valor na tela. A lista "nota" possui três elementos. "Nota: 1". "Nota: 2". "Nota: 3".
